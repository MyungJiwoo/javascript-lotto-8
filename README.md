# javascript-lotto-precourse

## Model

### Lotto

- [ ] 중복되지 않는 1~45 범위의 6개의 랜덤 숫자를 뽑는다.

### WinningNumbers

- [ ] 중복되지 않는 1~45 범위의 6개의 당첨 숫자를 저장한다.
  - [ ] 중복이 있다면 에러 발생후 다시 입력 받는다.
  - [ ] 1~45 범위의 양수가 아니라면 에러 발생 후 다시 입력 받는다.
  - [ ] 당첨 번호가 6개가 아니라면 에러 발생 후 다시 입력 받는다.
- [ ] 1~45 범위의 1개의 보너스 번호를 저장한다.
  - [ ] 당첨 번호와 중복되면 에러 발생후 다시 입력 받는다.
  - [ ] 1~45 범위의 양수가 아니라면 에러 발생 후 다시 입력 받는다.
  - [ ] 1개가 아니라면 에러 발생 후 다시 입력 받는다.
- [ ] Lotto의 당첨 결과를 반환한다.

### Rank

- [ ] 당첨 번호와 일치한 개수와 보너스 번호 포함 여부를 전달하면 등수를 반환한다.

### Purchase

- [ ] 로또를 구매할 금액을 1,000원 단위로 발행 가능한 로또 수량을 반환한다.
  - [ ] 1,000 이상의 양수가 아니라면 에러 발생 후 다시 입력 받는다.
  - [ ] 1,000 단위가 아니라면 에러 발생 후 다시 입력 받는다.

### Statistics

- [ ] 등수를 전달받아 각 등수별 몇 개씩 당첨되었는지 정리한다.
- [ ] 구입한 로또 금액과 당첨금을 바탕으로 수익률을 계산한다.
  - [ ] 수익률을 소수점 둘째 자리에서 반올림한다.

## Controller

### LottoController

- [ ] 구입 금액을 입력받아 유효한 Purchase를 저장한다.
- [ ] Purchase의 장수만큼 로또를 발행한다.
- [ ] 발행된 로또 목록을 출력한다.
- [ ] 당첨 번호(6개)를 입력받아 유효한 당첨 번호를 저장한다.
- [ ] 보너스 번호를 입력받아 유효한 WinningNumbers를 완성한다.
- [ ] 모든 로또의 등수를 판정하여 Statistics를 생성한다.
- [ ] 등수별 개수와 상금, 수익률을 출력한다.
- [ ] 프로그램을 종료한다.

## View

### PurchaseInput

- [ ] 로또를 구매할 1000 단위의 금액을 문자열로 입력 받는다.

### WinningNumbersInput

- [ ] 쉼표로 구분된 숫자 6개의 당첨 번호를 문자열로 입력 받는다.

### BonusNumberInput

- [ ] 한 개의 보너스 번호를 문자열로 입력 받는다.

### PurchasedLottosOutput

- [ ] 발행한 로또 내역을 출력한다.

### WinningResultsOutput

- [ ] 로또 당첨 내역을 출력한다.

### YieldRateOutput

- [ ] 수익률을 출력한다.

## Validation

### validationEmptyValue

- [ ] 공백 및 빈 문자열은 에러를 반환한다.
